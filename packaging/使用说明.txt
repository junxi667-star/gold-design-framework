黄金产业 AI 智能设计框架｜V0.6.0 Windows x64 便携演示包
=========================================================

一、第一次启动
1. 请先完整解压 ZIP，不要在压缩包预览窗口中运行。
2. 双击 START_DEMO.bat（或“启动演示.bat”）。
3. 系统会启动本机 127.0.0.1 上的演示服务和本地开发 Registry。
4. 浏览器将打开：http://127.0.0.1:4173/?demo=1

二、你看到的是什么
- V0.6.0 电影感前端。
- 需求解析、三个设计方向、单方向失败/重试、选择、细化、反馈和版本关系框架。
- 本地 Registry 使用包内 Ganache 和预编译 DesignRegistry，只在本机运行。
- Monad Testnet 页面只读取既有公开证据，不会替你发交易。

三、能力边界
- 默认不连接外部 AI，只显示明确标记的演示占位方向。
- 不真实生成图片，除非你另外配置并通过健康检查的同源 ComfyUI、模型和工作流。
- 不识别照片，不做 OCR。
- 不训练、微调或自动修改模型。
- 不自动联网采集黄金行业资料。
- 专家知识必须手动录入并审核通过后才能供设计调用。
- 链上或测试网记录不等于版权登记、原创认定、身份认证或生产上线。

四、联网说明
- 默认设计演示、本地 API 和本地 Registry 都只使用本机回环地址。
- 只有打开 Monad Testnet 只读页面时，系统才会访问公开测试网 RPC 做实时核验。
- 测试网无法访问时，页面应明确显示缓存或失败状态，不能当成实时核验成功。

五、数据与隐私
- 浏览器中的设计演示数据保存在该浏览器 IndexedDB。
- 本地后端状态和本地链运行文件保存在解压目录中。
- 不要向便携包目录放入私钥、助记词、API Key、客户附件或内部团队资料。
- 清除浏览器站点数据会删除该浏览器中的本地记录。

六、关闭
- 双击 STOP_DEMO.bat（或“关闭演示.bat”）。
- 仅关闭浏览器标签页不会停止后台服务和本地开发链。

七、故障排查
- 端口 4173 被占用：先关闭旧版演示服务。
- 端口 8545 被占用：先关闭其他本地 EVM；本包不会接管不属于自己的进程。
- 启动失败：查看解压目录中的 .gold-demo-evm.stderr.log。
- 安全软件拦截：先核对 ZIP 旁的 .zip.sha256.txt 和包内 SHA256SUMS.txt。
