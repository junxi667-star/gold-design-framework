# 黄金产业 AI 智能设计框架 v0.5.0

这是在旧版 v0.4.1 多轮设计框架上完成的兼容升级。原有“客户选方向—专业选项引导细化—多轮迭代—确认版本”流程、浏览器 IndexedDB 数据和本地演示能力继续保留；新版增加了可对接同源后端的任务与方向状态模型。

## 两个相互连接的闭环

1. 客户通过选择、修改和反馈，逐轮收敛设计方向。
2. 专家通过手动录入文本或照片、人工审核和显式调用，建设可追溯的专业知识入口。
3. 每次需求修订、生成任务、方向结果、反馈和父版本关系都保留关联信息。

## 本次兼容升级

- 每个生成任务可返回 3 个有名称、有说明的设计方向，不再混成无名称图片列表。
- 每张方向卡显示图片或占位图、状态、模型、耗时和失败原因。
- 支持部分成功、单个方向失败、只重试失败方向以及显式选择方向。
- 旧客户端仍可读取 `completedImages`；新客户端优先使用 `directions[]`。
- 需求解析结果可人工修改后确认；旧版内联结构化需求仍可创建设计任务。
- 任务、方向和幂等记录持久化到本地状态文件；相同幂等键可安全重放，内容冲突会被拒绝。
- 动态读取模型目录，不把前端写死在某一个图片模型上。
- 提示词版本、知识检索、结果反馈和版本关系接口继续保留。
- HTTP 服务限制回环地址、校验 `Host`/`Origin`，并要求写接口使用 JSON。

## 图片生成边界

- 默认“本地演示”不联网，只返回带清晰标识的占位方向。
- 手动切换“同源后端 API”后，只有 ComfyUI 可达、指定 Base/Refiner checkpoint 存在、工作流节点有效时，后端才会启用真实生成。
- 端口可达不等于模型可用；未满足条件时模型目录会明确显示不可用并拒绝真实任务。
- 当前项目不识别照片、不做 OCR、不自动联网采集，也不训练、微调或自动修改模型。
- `data/training/` 中的资料是需求解析种子与评测样例，不代表模型已经训练，也不证明黄金行业准确性。
- 占位结果、技术测试或本地连通性都不代表设计可生产、专业结论成立或真实图片质量达标。

## 运行与预览

需要 Node.js 20 或更高版本，无需安装第三方依赖。

```powershell
npm start
```

- 普通入口：`http://127.0.0.1:4173`
- 三方向卡片验收入口：`http://127.0.0.1:4173/?demo=1`

## 验证

```powershell
npm test
npm run evaluate:requirements
npm run check:comfyui
```

`evaluate:requirements` 只验证解析结构和程序流程不抛异常，不输出虚假的行业准确率。`check:comfyui` 用于检查本机 ComfyUI、checkpoint 和工作流是否真正就绪。

## 可选 ComfyUI 配置

复制 `.env.example` 中的变量到自己的启动环境，并按本机安装修改 checkpoint 名称。密钥、模型路径和内部资料不得写入浏览器代码。

当前正式工作流文件为 `workflows/sdxl_base_refiner_gold_v1_api.json`。远端接口失败时不会静默降级并伪装为真实生成。
