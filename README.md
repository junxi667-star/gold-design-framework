# 黄金产业 AI 智能设计框架

这是本地优先的前端框架，用于验证两个相互连接的闭环和一条可追溯的 AI 任务链：

1. 客户通过选择与反馈，逐轮收敛设计方向。
2. 专家通过手动录入、审核和关联资料，逐步建设专业知识入口。
3. AI 任务链通过需求修订、异步任务、反馈和父版本关系保留完整运行证据。

## 当前能力

- 新建设计主题并生成 3 个明确标注的演示占位方向。
- 选择方向、填写细化要求、保留版本历史并确认结果。
- 手动录入专业文本或照片，记录来源与授权说明。
- 专家审核资料；只有已批准资料才能显式关联到新设计。
- 数据与照片仅保存在当前浏览器的 IndexedDB 中。
- 导出当前设计记录为 JSON。
- 解析客户原话并允许人工修改结构化结果。
- 创建、轮询、取消和重试生成任务；本地模式只返回明确标注的占位结果。
- 基于已有结果创建细化子版本，并提交客户或专家反馈。
- 动态加载模型目录，不在页面中写死模型。
- 管理提示词正式版、历史版本、草稿、对比和发布门禁。
- 检索已审核知识；若远端响应混入未审核资料，前端拒绝整次响应。

## 明确不做

- 默认本地模式不联网；只有人工切换到“同源后端 API”才会请求当前站点的 `/api`。
- 不生成真实图片，不识别照片，不做 OCR。
- 不训练、微调或自动修改模型。
- 不把占位方向包装成 AI 或行业专家结论。
- 不判断克重、成本、工艺可行性或能否生产。

## 运行

需要 Node.js 20 或更高版本，无需安装第三方依赖。

```powershell
npm start
```

然后打开 `http://127.0.0.1:4173`。

## 测试

```powershell
npm test
```

## 后续接入点

当前保留原有 `MockDesignProvider`，并新增 `LocalAiClient` 与 `HttpAiClient`。远端接口失败时不会静默切换到本地演示；模型密钥必须保存在后端，不能写入浏览器或前端源码。

专业资料当前只保存原文、照片、人工标签与审核结论。未来必须在来源授权、专家审核、固定测试集和可回滚机制就绪后，才能增加解析、检索或训练能力。
