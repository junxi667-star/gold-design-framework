# 黄金珠宝AI需求解析训练资料 V1.0

用途：用于训练和评测“客户口语需求 -> 黄金珠宝行业结构化需求”的AI能力。

核心原则：AI可以解释客户口语中的风格、场景、偏好和限制，但不能把模糊词自动推断成明确参数。比如“年轻”“大气”“高级”“不要太重”只能进入风格、视觉重量或待确认字段，不能直接变成“5克以内”“必须实心”“预算很高”等结论。

## 一、黄金需求字段分类表

### 1. 基础字段

| 字段 | 含义 | 常见值 | AI解析注意 |
|---|---|---|---|
| 产品类型 | 客户要做或购买的首饰类别 | 戒指、手镯、手链、项链、吊坠、耳钉、耳环、耳坠、金锁、金条、摆件 | 必须从客户原话或上下文判断，不确定则待确认 |
| 黄金类型 | 材质和成色要求 | 足金、硬足金、古法金、3D硬金、5G黄金、18K金、22K金 | 没说就写未说明，不要自动默认足金999 |
| 目标人群 | 佩戴者或收礼对象 | 年轻女性、中年女性、母亲、男士、儿童、老人、情侣、新娘 | “妈妈”通常是中年或老年女性，但年龄仍可待确认 |
| 使用场景 | 为什么买、什么时候戴 | 送礼、婚嫁、生日、情人节、日常佩戴、商务、收藏、节庆 | 场景影响风格，不直接决定克重 |
| 佩戴频率 | 使用强度 | 日常、偶尔、重要场合、收藏展示 | 日常佩戴要关注舒适度、勾挂风险、结构牢固 |
| 风格关键词 | 客户对整体感觉的表达 | 年轻、简约、大气、古法、国潮、贵气、低调、可爱、商务 | 风格词不是参数词 |
| 图案元素 | 明确要求出现的造型或符号 | 莲花、祥云、龙凤、生肖、福字、如意、蝴蝶、葫芦、竹节、几何 | 必须保留的元素要单独标记 |
| 寓意要求 | 客户希望表达的祝福或意义 | 平安、招财、福气、长寿、爱情、事业、学业、健康 | 可转换成合适纹样，但要避免过度堆元素 |
| 克重要求 | 明确的重量范围或倾向 | 5g以内、10-15g、不要太重、显大不重 | 没有明确数字时只能写偏轻/未说明/待确认 |
| 克重视觉 | 看起来轻或重 | 轻盈、有存在感、厚重、大气、显大 | 克重视觉不等于实际克重 |
| 预算 | 价格范围 | 3000以内、5000左右、1万以内、未说明 | 预算和克重受金价影响，应进入待确认 |
| 尺寸参数 | 身体尺寸和首饰尺寸 | 戒圈号、手围、链长、吊坠尺寸、耳针长度 | 缺失时必须待确认 |
| 结构形式 | 首饰结构 | 开口、闭口、活口、固定圈、空心、实心、镂空、组合件、可活动 | 影响生产可行性和耐用性 |
| 工艺要求 | 表面和制造工艺 | 古法、拉丝、磨砂、亮面、喷砂、錾刻、浮雕、镂空、电铸、珐琅、镶嵌 | 客户没说工艺时不要强行指定 |
| 表面效果 | 视觉质感 | 光面、哑光、磨砂、细腻纹理、镜面、做旧 | 可由“高级、低调、古法感”辅助推断，但仍可待确认 |
| 镶嵌要求 | 是否需要宝石或其他材质 | 不镶嵌、钻石、翡翠、玉石、珍珠、彩宝、珐琅 | “高级”不等于必须镶钻 |
| 生产可行性 | 结构是否可能加工 | 可加工、需简化、风险较高、待专家确认 | 训练时要让AI识别悬空、过细、尖锐、易断风险 |
| 佩戴舒适性 | 是否适合实际佩戴 | 圆润、不刮手、不勾头发、不硌手、不压耳 | 日常款、儿童款、老人款尤其重要 |
| 安全风险 | 对佩戴者或产品的风险 | 尖锐、毛刺、易断、易变形、过重、扣位不牢 | 儿童、老人、耳饰、手镯要重点关注 |
| 必须保留 | 客户明确要求不能删的内容 | 莲花元素、生肖龙、原有轮廓、某个图案 | 修改生成时尤其重要 |
| 不希望出现 | 客户明确排斥内容 | 太花、太土、太重、太传统、太夸张、尖锐、复杂密集纹样 | 必须作为负向约束 |
| 参考资料 | 客户上传或指定的参考 | 图片、手稿、旧款、竞品图、门店案例 | 未审核资料不能直接进入训练数据 |
| 版权状态 | 参考资料能否用于训练或商用 | 已授权、仅参考、来源不明、禁止训练 | 来源不清图片不能训练模型 |
| 待确认问题 | AI不能确定但影响设计的内容 | 预算、黄金类型、克重、尺寸、链长、戒圈号、手围、是否镶嵌 | 待确认是合格输出的一部分 |

### 2. 建议新增的黄金行业字段

| 字段 | 为什么需要 |
|---|---|
| 饰品命名合规字段 | 黄金首饰正式命名应按材料/纯度/宝石/品种表达，避免把营销词直接放进规范名称 |
| 金属硬度/工艺适配 | 足金较软，硬足金、K金等在硬度和造型承载上不同，影响细节、开口、镶嵌和耐用性 |
| 结构承重点 | 吊坠扣头、戒臂、耳针、手镯开口、连接环等位置要考虑强度 |
| 佩戴接触面 | 戒指内圈、手镯内壁、耳饰针托、项链扣位要考虑舒适和安全 |
| 加工方式倾向 | 倒模、油压、电铸、CNC、手工錾刻、镶嵌、焊接等会影响可实现程度 |
| 售卖属性 | 按克销售、按件销售、定制款、礼品款、收藏款会影响设计表达 |
| 版本关系 | 新生成、基于旧图修改、保留轮廓、只改纹样、只改材质，避免每次从零生成 |

## 二、客户常见说法与正确结构化结果

以下40条覆盖戒指、项链、吊坠、手镯、手链、耳饰、儿童金饰、婚嫁、男士、节庆和修改类需求。

### 1. 妈妈手镯

客户说法：我想给妈妈买一个手镯，看起来大气一点，但是不要太花。

正确结构化结果：

| 字段 | 正确结果 |
|---|---|
| 产品类型 | 手镯 |
| 目标人群 | 中年女性、母亲 |
| 使用场景 | 送礼 |
| 风格 | 大气、稳重、简洁 |
| 图案要求 | 不要复杂花纹 |
| 克重要求 | 未说明 |
| 黄金类型 | 未说明 |
| 待确认问题 | 预算、黄金类型、手围、目标克重 |

AI禁止误解：不能因为“大气”就自动判断为很重或实心厚镯。

### 2. 女朋友莲花吊坠

客户说法：想做一个送女朋友的莲花吊坠，年轻一点，不要太重。

正确结构化结果：

| 字段 | 正确结果 |
|---|---|
| 产品类型 | 吊坠 |
| 目标人群 | 年轻女性、女朋友 |
| 使用场景 | 送礼、日常佩戴 |
| 风格 | 年轻、简约 |
| 图案元素 | 莲花 |
| 克重要求 | 偏轻，具体克重未说明 |
| 必须保留 | 莲花元素 |
| 不希望出现 | 过于厚重、复杂 |
| 待确认问题 | 黄金类型、预算、具体克重、吊坠尺寸、是否配链 |

AI禁止误解：不能把“年轻”直接等同于5克以内。

### 3. 老人福字戒指

客户说法：老人戴的黄金戒指，要有福气感，别太新潮。

正确结构化结果：产品类型=戒指；目标人群=老人；使用场景=自戴或送礼未说明；风格=传统、稳重、吉祥；图案元素=福字、祥云、如意可选；不希望出现=过度年轻化、夸张潮流；待确认=戒圈号、黄金类型、预算、克重。

AI禁止误解：不能因为“老人戴”就默认大克重或复杂龙凤。

### 4. 男士低调项链

客户说法：给男朋友买条黄金项链，他不喜欢太张扬，要低调一点。

正确结构化结果：产品类型=项链；目标人群=年轻或成年男性；使用场景=送礼、日常佩戴；风格=低调、简洁、成熟；图案元素=未说明；不希望出现=夸张粗链、女性化装饰；待确认=链长、链型、预算、克重、黄金类型。

AI禁止误解：低调不等于极细，也不等于没有黄金质感。

### 5. 婚嫁龙凤戒指

客户说法：结婚用的戒指，想要传统一点，有龙凤元素。

正确结构化结果：产品类型=戒指；使用场景=婚嫁；风格=传统、喜庆、仪式感；图案元素=龙凤；寓意=婚姻吉祥、成双成对；必须保留=龙凤元素；待确认=男女款或单只、戒圈号、黄金类型、预算、克重、是否需要对戒。

AI禁止误解：不能只画成普通龙纹戒指而忽略婚嫁和凤元素。

### 6. 日常小吊坠

客户说法：想要一个每天戴的小吊坠，不要刮衣服，也不要太显眼。

正确结构化结果：产品类型=吊坠；使用场景=日常佩戴；风格=低调、小巧、圆润；工艺要求=边缘圆滑、减少尖角；不希望出现=尖锐结构、易勾挂、过度夸张；待确认=元素、尺寸、克重、是否配链、预算。

AI禁止误解：小巧不等于必须薄到易变形。

### 7. 古法金手镯

客户说法：我喜欢古法金那种感觉，但不要太老气。

正确结构化结果：产品类型=未说明；黄金类型/工艺倾向=古法金风格；风格=温润、哑光、传统中带现代；不希望出现=过度老气、传统元素堆满；待确认=产品类型、预算、克重、尺寸、具体图案。

AI禁止误解：古法感不等于一定复杂宫廷纹。

### 8. 儿童平安锁

客户说法：给小孩买个平安锁，简单一点，寓意好就行。

正确结构化结果：产品类型=金锁/吊坠；目标人群=儿童；使用场景=送礼、祝福；寓意=平安、健康；风格=简洁、可爱、圆润；安全要求=边缘圆滑、避免尖锐和小零件脱落；待确认=孩子年龄、克重、预算、是否配绳或链。

AI禁止误解：儿童款不能做尖锐、细碎、易断结构。

### 9. 生肖龙吊坠

客户说法：今年想做个生肖龙吊坠，别太凶，适合女生。

正确结构化结果：产品类型=吊坠；图案元素=生肖龙；目标人群=女性；风格=柔和、精致、年轻或优雅；不希望出现=攻击性强、表情凶、线条过硬；待确认=年龄、黄金类型、预算、克重、是否配链。

AI禁止误解：龙不一定要威猛厚重。

### 10. 金耳钉

客户说法：想买个耳钉，上班能戴，别太夸张。

正确结构化结果：产品类型=耳钉；使用场景=通勤、日常佩戴；风格=简约、低调、精致；佩戴要求=轻便、不压耳；不希望出现=大体积、长耳坠、夸张装饰；待确认=是否过敏、尺寸、黄金类型、预算。

AI禁止误解：上班戴不等于没有设计感。

### 11. 蝴蝶项链

客户说法：想要蝴蝶元素的项链，甜美一点，但不要幼稚。

正确结构化结果：产品类型=项链或吊坠项链；图案元素=蝴蝶；目标人群=女性；风格=甜美、精致、轻熟；不希望出现=儿童化、卡通化、过度可爱；待确认=链长、吊坠尺寸、预算、黄金类型、是否镶嵌。

AI禁止误解：甜美不等于卡通。

### 12. 男士戒指

客户说法：男士戒指，想要有力量感，但是不要暴发户。

正确结构化结果：产品类型=戒指；目标人群=男性；风格=力量感、沉稳、低调；不希望出现=过度夸张、过宽、过多财富符号；图案元素=未说明；待确认=戒圈号、克重、预算、黄金类型。

AI禁止误解：力量感不等于越粗越好。

### 13. 生日礼物手链

客户说法：生日送朋友的手链，希望特别一点，不要跟别人一样。

正确结构化结果：产品类型=手链；使用场景=生日礼物；目标人群=朋友，性别年龄未说明；风格=有辨识度、个性化；不希望出现=大众撞款；待确认=性别、年龄、预算、克重、手围、元素、是否刻字。

AI禁止误解：特别不等于复杂堆满元素。

### 14. 商务吊坠

客户说法：客户是做生意的，想送个黄金吊坠，别太俗，要有好寓意。

正确结构化结果：产品类型=吊坠；目标人群=商务客户；使用场景=商务送礼；寓意=招财、顺利、稳健；风格=高级、低调、商务；不希望出现=俗气、过度直白、夸张财神形象；待确认=预算、黄金类型、克重、对方性别年龄、是否配链。

AI禁止误解：招财不一定要直接用财神或大元宝。

### 15. 简约素圈戒指

客户说法：我就想要一个素一点的黄金戒指，平时戴舒服。

正确结构化结果：产品类型=戒指；风格=素圈、简约；使用场景=日常佩戴；佩戴要求=内圈舒适、边缘圆润；图案元素=无或少；待确认=戒圈号、宽度、克重、黄金类型、预算。

AI禁止误解：素不等于完全没有比例设计。

### 16. 高级感吊坠

客户说法：做个吊坠，要高级一点，不要看起来廉价。

正确结构化结果：产品类型=吊坠；风格=高级、精致；表面效果=比例协调、做工细腻、适当留白；不希望出现=廉价感、粗糙、元素堆砌；待确认=元素、目标人群、预算、黄金类型、克重、是否镶嵌。

AI禁止误解：高级不等于必须镶钻或预算很高。

### 17. 送妈妈项链

客户说法：给妈妈买项链，要显得有气质，别太年轻。

正确结构化结果：产品类型=项链；目标人群=中年女性、母亲；使用场景=送礼；风格=优雅、稳重、有气质；不希望出现=过度少女感、卡通感；待确认=链长、吊坠元素、预算、黄金类型、克重。

AI禁止误解：稳重不等于传统复杂。

### 18. 情人节爱心吊坠

客户说法：情人节想送爱心吊坠，但不要太俗。

正确结构化结果：产品类型=吊坠；使用场景=情人节礼物；图案元素=爱心；风格=浪漫、简洁、有设计感；不希望出现=俗套大爱心、过度甜腻；待确认=目标人群年龄、预算、黄金类型、克重、是否配链。

AI禁止误解：爱心元素必须保留，但表达方式可以抽象化。

### 19. 福字手链

客户说法：想做一条带福字的手链，别做得太老。

正确结构化结果：产品类型=手链；图案元素=福字；寓意=福气、好运；风格=传统元素现代化；不希望出现=老气、复杂传统纹样；待确认=手围、链型、预算、黄金类型、克重。

AI禁止误解：福字不等于一定使用大面积传统红金配色。

### 20. 古风耳坠

客户说法：耳坠想要古风一点，但日常也能戴。

正确结构化结果：产品类型=耳坠；风格=古风、轻盈、日常化；佩戴要求=不过重、不拉耳、结构稳；图案元素=未说明，可选莲花、祥云、流苏等；不希望出现=过长、过重、舞台化；待确认=耳洞情况、长度、预算、黄金类型、克重。

### 21. 宝宝手镯

客户说法：宝宝戴的小手镯，安全第一，不要尖尖的。

正确结构化结果：产品类型=儿童手镯；目标人群=婴幼儿或儿童；核心要求=安全、圆润；不希望出现=尖角、毛刺、小零件脱落、易变形开口；待确认=年龄、手围、是否铃铛、预算、黄金类型、克重。

客户说法：结婚戴的黄金手镯，要喜庆，但别太密密麻麻。

正确结构化结果：产品类型=手镯；使用场景=婚嫁；风格=喜庆、大气；图案元素=龙凤、囍字、祥云、花卉可选；不希望出现=纹样过密、视觉拥挤；待确认=手围、预算、黄金类型、克重、是否成对。

### 23. 转运珠

客户说法：想买个转运珠，简单耐看一点。

## 五、标准测试需求集

固定用于每次换模型、换提示词、换图片生成服务后的对比测试。建议每条都要求模型输出：结构化字段、待确认问题、生成提示词、负向提示词、生产风险、专家评分。

### 测试1：年轻女性莲花吊坠

客户需求：想做一个送女朋友的莲花吊坠，风格年轻简约，不要显得太重，适合日常佩戴。

标准结构化需求：

| 字段 | 内容 |
|---|---|
| 产品类型 | 吊坠 |
| 目标人群 | 年轻女性 |
| 使用场景 | 礼物、日常佩戴 |
| 风格 | 年轻、简约 |
| 图案元素 | 莲花 |
| 克重视觉 | 轻量 |
| 工艺要求 | 表面圆润，不要尖锐 |
| 禁止出现 | 复杂密集纹样、厚重结构 |
| 待确认 | 黄金类型、预算、具体克重、吊坠尺寸、是否配链 |

专家评分重点：是否明显是吊坠；莲花元素是否清楚；是否符合年轻女性审美；是否显得轻巧；是否适合日常佩戴；结构是否可加工；是否存在尖锐、易断或悬空结构。

严重问题示例：生成成戒指；莲花元素不明显；结构非常厚重；花纹过于复杂；出现明显无法加工的悬空结构。

### 测试2：妈妈大气手镯

客户需求：我想给妈妈买一个手镯，看起来大气一点，但是不要太花。

标准结构化需求：产品类型=手镯；目标人群=中年女性、母亲；使用场景=送礼；风格=大气、稳重、简洁；图案要求=不要复杂花纹；克重要求=未说明；黄金类型=未说明；待确认=预算、黄金类型、手围、目标克重。

评分重点：是否是手镯；是否大气但不复杂；是否避免把大气误解为大克重；是否保留送妈妈的稳重感。

严重问题：生成成项链；满雕复杂花纹；自动指定高克重；过度年轻少女化。

### 测试3：婚嫁龙凤戒指

客户需求：结婚用的黄金戒指，想要传统一点，有龙凤元素，喜庆但不要太挤。

标准结构化需求：产品类型=戒指；使用场景=婚嫁；元素=龙凤；风格=传统、喜庆；不希望出现=纹样过密、视觉拥挤；待确认=戒圈号、是否对戒、黄金类型、预算、克重。

评分重点：龙凤是否清楚；婚嫁属性是否明显；戒指结构是否合理；纹样是否不过密。

严重问题：只出现龙无凤；生成手镯；纹样密到无法加工；戒臂过细易断。

### 测试4：男士低调项链

客户需求：给男朋友买条黄金项链，他不喜欢太张扬，要低调一点，平时也能戴。

标准结构化需求：产品类型=项链；目标人群=男性；使用场景=礼物、日常佩戴；风格=低调、成熟、简洁；禁止出现=夸张粗链、女性化吊坠、过度装饰；待确认=链型、链长、克重、预算、黄金类型。

严重问题：过粗暴发户风；生成女性吊坠；链节不合理。

### 测试5：儿童平安锁

客户需求：给小孩买个平安锁，简单一点，安全第一，不要尖尖的。

标准结构化需求：产品类型=平安锁/儿童吊坠；目标人群=儿童；寓意=平安健康；风格=简洁、圆润；安全要求=无尖角、无易脱落小件；待确认=年龄、克重、预算、配绳或配链。

评分重点：儿童安全；平安锁识别度；边缘是否圆润；结构是否结实。

严重问题：尖角多；小零件悬空；过重；生成成人吊坠。

### 测试6：古法金年轻化手镯

客户需求：喜欢古法金那种温润质感，想做手镯，但不要太老气。

标准结构化需求：产品类型=手镯；工艺/风格=古法金、哑光、温润；风格调整=年轻化、简洁；禁止出现=过度传统满雕、老气厚重；待确认=手围、预算、克重、是否真实古法工艺。

评分重点：古法质感；不过度老气；手镯结构合理；纹样不过密。

严重问题：亮面现代感过强；过度宫廷复杂；自动大克重。

### 测试7：商务招财吊坠

客户需求：送做生意的客户一个黄金吊坠，要有招财寓意，但是不能俗。

标准结构化需求：产品类型=吊坠；目标人群=商务客户；使用场景=商务送礼；寓意=招财、顺利；风格=高级、克制、商务；禁止出现=夸张财神、大元宝堆叠、俗气符号；待确认=性别年龄、预算、黄金类型、克重。

评分重点：商务礼品感；寓意清楚但不俗；吊坠结构可佩戴；黄金质感。

严重问题：卡通财神；元素堆满；像摆件不是吊坠。

### 测试8：日常耳钉

客户需求：想买个上班戴的黄金耳钉，精致一点，不要太夸张，也不要压耳朵。

标准结构化需求：产品类型=耳钉；场景=通勤、日常；风格=精致、低调；佩戴要求=轻便、不压耳；禁止出现=过大、长坠、尖锐；待确认=尺寸、耳针材质、预算、黄金类型。

评分重点：耳钉识别；轻便；通勤适配；结构安全。

严重问题：生成耳坠；过大过重；尖锐边缘。

### 测试9：中国风年轻项链

客户需求：想要中国风项链，但不要做成奶奶款，年轻人平时能戴。

标准结构化需求：产品类型=项链；风格=国风、年轻、日常；元素=可选祥云、莲花、窗棂、竹节等抽象化元素；禁止出现=老气、满雕、传统元素堆砌；待确认=链长、吊坠元素、预算、黄金类型、克重。

评分重点：国风识别；年轻化；日常佩戴；不过度复杂。

严重问题：传统元素堆满；生成长辈款；结构容易勾挂。

### 测试10：低克重显大的手镯

客户需求：手镯不要太重，但是看起来不能太小气，预算有限。

标准结构化需求：产品类型=手镯；预算=有限但未给数字；克重倾向=偏轻；克重视觉=有存在感；结构建议=轻量化宽面、空心/半空心可能，但需确认工艺和耐用性；待确认=预算、手围、目标克重、黄金类型。

评分重点：不能自动报克重；视觉体量和轻量化平衡；结构不能薄到易变形。

严重问题：自动指定具体克重；做成厚重实心；薄片结构明显易变形。

### 测试11：保留轮廓简化花纹

客户需求：这个旧吊坠的轮廓我喜欢，保留形状，把花纹改简单一点。

标准结构化需求：任务类型=基于参考图修改；必须保留=原有轮廓；修改范围=简化花纹；禁止出现=改变产品类型、大改外形、从零生成；待确认=原图来源、版权状态、黄金类型、加工限制。

评分重点：是否延续原图；是否只简化花纹；是否保持可加工结构。

严重问题：完全换款；轮廓丢失；生成无关图案。

### 测试12：只改古法质感

客户需求：造型不要动，把表面换成古法金那种哑光温润的感觉。

标准结构化需求：任务类型=材质/表面效果修改；必须保留=造型、结构、比例；修改范围=古法金视觉质感；禁止出现=图案改变、结构改变、产品类型改变；待确认=是否真实采用古法工艺。

评分重点：造型一致；古法哑光质感明显；无结构偏移。

严重问题：重画新造型；新增复杂花纹；只变颜色无质感。

### 测试13：男士力量感戒指

客户需求：男士黄金戒指，想要有力量感，但是不要暴发户，也不要太宽。

标准结构化需求：产品类型=戒指；目标人群=男士；风格=力量感、沉稳、低调；限制=不要太宽、不要夸张财富感；待确认=戒圈号、宽度、预算、黄金类型、克重。

评分重点：男士风格；比例不过宽；不俗气；戒指结构可佩戴。

严重问题：大面积元宝纹；过宽压手；自动重克重。

### 测试14：闺蜜手链成套

客户需求：想做两条闺蜜手链，风格类似，但不要完全一样。

标准结构化需求：产品类型=手链；使用场景=友情礼物；版本关系=成套、呼应、有差异；风格=年轻、轻巧；待确认=手围、预算、元素、黄金类型、克重、刻字内容。

评分重点：两条之间有关系；差异不过大；年轻日常；结构牢固。

严重问题：两条毫无关联；完全复制；生成项链。

### 测试15：金镶玉协调吊坠

客户需求：想做金镶玉吊坠，黄金部分主要衬托玉，不要盖住玉。

标准结构化需求：产品类型=吊坠；材质组合=黄金+玉石；设计重点=黄金衬托玉石；禁止出现=黄金遮挡玉石、主体关系颠倒；待确认=玉石尺寸形状、镶嵌方式、预算、黄金类型、克重。

评分重点：主次关系；镶嵌合理；吊坠结构可佩戴；黄金和玉石协调。

严重问题：黄金遮住玉；玉石不明显；镶嵌结构不稳。

## 六、客户对接AI时的痛点和疑难点

### 1. 口语需求模糊

客户常说“大气、年轻、高级、不要俗、不要太重”，但这些词没有明确尺寸、克重、工艺参数。AI如果直接猜参数，会导致设计偏离。

对应方法：建立模糊词解释库，输出“可理解含义”和“不能直接推断内容”。

### 2. 客户没有产品知识

客户可能分不清项链、吊坠、链坠、耳钉、耳环、耳坠，也不清楚足金、K金、硬金、古法金的区别。

对应方法：字段里加入“待确认问题”和“术语澄清”，让AI先问清楚，而不是装懂。

### 3. 风格词和工艺词混用

客户说“古法一点”，可能是指哑光温润的视觉风格，也可能是真正要古法金工艺。

对应方法：把“视觉风格”和“真实工艺”拆开，真实工艺必须待确认。

### 4. 视觉重量和实际克重混淆

客户说“不要太重”可能是担心佩戴累、预算高、看起来厚重，也可能有明确克重限制。

对应方法：拆成“克重视觉”“实际克重”“预算”三个字段。

### 5. 好看但不能生产

AI容易生成悬空结构、过细连接、尖锐花瓣、过密镂空、无法焊接或容易变形的设计。

对应方法：每次输出增加“生产风险字段”，让行业专家审核。

### 6. 修改任务容易从零生成

客户说“保留造型，只改花纹”，AI可能重新生成完全不同的款。

对应方法：修改任务必须记录“必须保留、允许修改、禁止修改”。

### 7. 参考图版权风险

客户上传图片可能来自网络、竞品、未授权作品，不能直接进入训练数据。

对应方法：所有资料增加版权状态：已授权、仅内部参考、来源不明、禁止训练。

### 8. 行业命名和销售表达不一致

市场会说3D硬金、5G黄金、千足金等，但正式命名和标识要遵守现行标准口径。

对应方法：系统里区分“客户原话/营销词”和“规范字段/合规名称”。

### 9. 多角色理解不一致

客户、销售、设计师、建模师、工厂对同一句话理解不同。

对应方法：结构化结果要同时服务销售沟通、AI出图、专家审核和后续建模。

### 10. 缺少固定评测集

如果每次换模型都用不同题目，很难判断提示词是否变好。

对应方法：固定15条以上标准测试需求，记录模型、提示词版本、生成结果和专家评分。

## 七、AI训练与评测方法

### 1. 训练数据格式建议

每条训练数据建议包含：

- 客户原话
- 正确结构化字段
- 模糊词解释
- 待确认问题
- 必须保留
- 不希望出现
- 生产风险
- 专家评分
- 严重错误示例
- 版权状态

### 2. 推荐JSON字段

```json
{
  "customer_text": "想做一个送女朋友的莲花吊坠，年轻一点，不要太重。",
  "product_type": "吊坠",
  "gold_type": "未说明",
  "target_user": ["年轻女性", "女朋友"],
  "usage_scene": ["送礼", "日常佩戴"],
  "style": ["年轻", "简约"],
  "motifs": ["莲花"],
  "weight_requirement": "偏轻，具体克重未说明",
  "visual_weight": "轻量",
  "budget": "未说明",
  "craft_requirement": "未说明",
  "must_keep": ["莲花元素"],
  "avoid": ["过于厚重", "复杂密集纹样"],
  "manufacturing_risks": ["尖锐花瓣", "过细连接", "悬空结构"],
  "questions_to_confirm": ["黄金类型", "预算", "具体克重", "吊坠尺寸", "是否配链"],
  "do_not_infer": ["不要把年轻推断为5克以内", "不要把不要太重推断为具体克重"]
}
```

### 3. 专家评分维度

| 评分项 | 说明 |
|---|---|
| 需求理解准确性 | 是否正确识别产品、人群、场景、风格、元素 |
| 字段完整度 | 是否列出必要字段和待确认问题 |
| 不乱猜参数 | 是否避免把模糊词变成明确克重、预算、材质 |
| 行业专业性 | 是否符合黄金首饰术语、材质、工艺常识 |
| 设计一致性 | 图像是否和结构化需求一致 |
| 生产可行性 | 是否避免悬空、过细、尖锐、易断、易变形结构 |
| 佩戴舒适性 | 是否考虑日常佩戴、儿童/老人安全、耳饰重量等 |
| 修改延续性 | 是否保留客户要求保留的造型、元素和版本关系 |
| 版权合规 | 是否避免使用来源不明资料训练或商用复制 |

建议分值：每项1-5分，总分40分或45分。低于60%需要回炉修改。

### 4. 严重错误类型

- 产品类型错误：吊坠生成成戒指，耳钉生成成耳坠。
- 核心元素丢失：莲花、龙凤、福字、生肖等客户明确要求的元素不明显。
- 模糊词乱推断：把“大气”变成高克重，把“年轻”变成5克以内。
- 修改不延续：客户要求保留轮廓，AI却完全换款。
- 生产不可行：悬空结构、过细连接、尖锐边缘、复杂到无法加工。
- 佩戴不安全：儿童款有尖角，小耳钉过重，戒指刮手，项链勾头发。
- 版权风险：复制参考图或竞品图，来源不明资料进入训练集。
- 合规风险：把不规范营销称呼当成正式商品名称。
